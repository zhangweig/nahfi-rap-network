# 替换像素头像

1. 把自己生成的 PNG / WebP / GIF / JPEG 放在这个目录，例如 `yitai.png`。
2. 打开王以太档案，点击右上角铅笔，在“像素头像地址”填 `/avatars/yitai.png`。
3. 提交后进入站长审核台批准，地图、人物名录和档案会同时更新。

建议使用 64 × 64 或 128 × 128 的透明 PNG，保持正方形和统一像素密度。路径区分大小写；文件名建议使用英文字母、数字和连字符。

也可以填 HTTPS 图片地址。没有地址或加载失败时显示内置像素占位头像。图片不会上传到数据库；数据库只保存经审核的图片地址。部署时要一并携带这些本地图片。

维护者也可在基础人物数据中设置可选字段 `avatarUrl`。已经通过社区审核的人物覆盖层优先于基础数据；后续修改建议继续使用页面编辑流程。
