# 美术方向与改造方案（不动代码）

> 审计对象：Alpha 0.5 现有界面（地图 / 人物 / 作品 / 详情抽屉 / 移动端）
> 审计方式：源码读取 + 1440 / 1024 / 390 三档实机截图 + 对比度计算
> 本文只给方向、规范与执行顺序，不含代码改动。

---

## 一、核心判断：两套语言在打架

产品的内容语言是**档案**：聚落、考据、来源、作品版本、待考据之岛、站长审核、证据说明。
界面语言却是**街机 HUD**：霓虹描边、发光文字、扫描线、雷达、极光、浮尘、技能条、"Lv.47"、波纹动画、"345 LINKS"。

结果是：独特性来自**内容与空间隐喻**（省份聚落 + 人物节点 + 关系线），而最容易被认成"AI 做的"的部分，恰恰是视觉表皮。

**方向结论：让档案赢，只留一个动态狠招（关系图本身）。**

## 二、量化诊断

| # | 问题 | 证据 | 影响 |
|---|------|------|------|
| 1 | 字号体系塌陷 | `neon.css` 161 条 `font-size` 声明，**130 条 < 12px**（最低 6.5px：`bt-notes`）；面板统计标签 7px、分区标签 9px、时间轴年份 9px | 正常 DPI 下不可读，逼用户放大浏览器 |
| 2 | 对比度不达标 | `#3f6377`/`#050a11` = **3.08**、placeholder `#43647a`/`#081320` = **2.97**、时间轴 `#4f7288`/`#04090f` = **3.90**、副标题 `#54748c` = **4.08**（AA 要求 4.5） | 小字号 + 低对比叠加，弱视/老屏直接丢失信息 |
| 3 | 色彩语义自相矛盾 | 省份色：四川 `#ff3d6e`、上海 `#35d6ff`、湖南 `#35ff9e`、福建 `#b07cff`；关系色：member `#35d6ff`、affiliation `#35ff9e`、production `#b07cff`——**3/4 关系色与省份色同值** | 同一画面里"青色"既是上海又是组合关系，颜色等于没信息 |

| 7 | 空省份占满画布 | 34 个分区全画彩色框，其中 22 个是 0–1 人（甘肃 1、青海 0、宁夏 0…），仍占约 40% 面积 | 主信息（四川 35、ARCHIVE 100）被稀释 |
| 8 | 人物卡是游戏面板 | `作品密度 48 / 合作广度 97 / 圈层跨度 36` + `Lv.47` + 波形动画，数值无出处 | 与"每条记录都有来源"的产品承诺正面冲突，是可信度问题而非审美问题 |
| 9 | 目录页没有美术方向 | 人物页 6×N 等大卡片、作品页 5 列同样卡片，元信息 9–11px | 离开"世界"进入"后台表格"，与地图毫无血缘 |
| 10 | 移动端招牌功能失效 | 390px：抽屉 `max-height:64%` 盖住画布、缩放按钮 `display:none`、rail 隐藏、时间轴 6.5–9px | 手机上"关系网"这个核心资产不可用 |

## 三、三条方向

### 方向 A · 黑胶档案（推荐）
唱片内页 / 人口普查表的编辑设计。墨黑底（`#14120F`，偏暖、非纯黑）、米白字（`#F2ECE1`）、**唯一强调色朱红**（`#C9402A`）、暖灰次级（`#8C8378`）。
分区不再是霓虹盒子，而是档案卡片格：1px 发丝边 + 左上角编号 `SC · 35` + 顶部细线不封口；密度用底纹点阵表达（人越多点越密）。关系统一墨色，用**线型**区分类型。标题用衬线（Noto Serif SC），正文系统黑体，mono 只用于编号/年份/计数。

- 优点：与内容同源；一次性解决对比度、发光喧闹、色义冲突；改动集中在 token 层；像素头像可自然退化为"空档案框 + 编号"
- 代价：需要重排字号体系，画布密度要重新算
- 风险：低

### 方向 B · 双色印刷（Risograph）
纸白 + 墨黑 + 一种荧光墨，套印错位 + 网点。分区成为套印色块，重叠处 multiply 变深——正好表达关系密度；头像做 1-bit 网点；关系线点线。只有两色，降噪最彻底，街头感与实验性最强。

- 优点：辨识度最高，"这是怎么做出来的"级
- 代价：网点化照片需要处理管线与降级方案；对比度需逐对校验；实现成本最高
- 风险：中高

### 方向 C · 夜间电台
保留深色，去掉全部霓虹：极深灰蓝（`#0C1015`）、真实照片去饱和带颗粒、琥珀单光源（`#D89A5E`）、靠字重与留白做层级。分区退成几乎透明的省界网格，只有有人的省份微微亮起；关系线默认几乎不可见，选中才亮。

- 优点：情绪最贴近说唱（深夜、私密、放一张 mixtape）
- 代价：暗场弱对比在小屏/强光下易糊；需要很硬的对比度纪律
- 风险：中

**建议**：以 A 为骨架，吸收 C 的照片处理（去饱和 + 颗粒）与"默认低亮、聚焦才亮"的边线策略，B 的**点阵密度**只借一个细节用于表达分区人口密度。不做三合一混搭，只取两个可复用的技法。

## 四、执行方案

### P0 立规矩（半天，零代码）
1. 确定唯一强调色（建议朱红 `#C9402A`）。
2. **发光白名单**只留三处：选中节点、选中路径、空状态主行动。其余一律无 glow。
3. 层级只允许用：字号 / 字重 / 留白 / 位置。禁止用颜色或光晕区分主次。
4. 冻结装饰：不再新增背景伪元素与 `infinite` 动画。

### P1 地基：排版 + 色彩 token
- **字阶**：11（仅编号/刻度）/ 12 / 13（正文下限）/ 15 / 19 / 26 / 38，行高 1.6–1.75。取消 6.5–10px 全部层级。
- **字体**：标题 Noto Serif SC（Archivo/思源宋类似气质的替代品也行）；正文 `"PingFang SC","Microsoft YaHei"`；计数用 `ui-monospace`。
- **色板**（收敛到 ~24 个 token，现 220 个 hex）：
  - 底 `#14120F` / 面 `#1B1815` / 浮层 `#221E1A`
  - 文字 `#F2ECE1`（主）/ `#C8BFB2`（次，≈8:1）/ `#8C8378`（弱，≈4.6:1）
  - 强调 `#C9402A`；描边 `#F2ECE1` @ 8% / 14%
- **圆角**：数据表面 2px、控件 6px、弹窗 8px。取消 12–16px 大圆角 + 内发光。
- **验收**：正文与弱文字全部 ≥ 4.5:1。

### P2 画布：分区与节点重构
- 分区：删除彩边/内虚线/径向渐变/外发光四层 → 1px 发丝边 + 编号 + 人数 + 底纹密度。
- 空省份：不再进主画布，收进底部"未收录省份"一行文字；或退为纯虚线网格 + `—`。
- 节点：3 档固定尺寸；照片统一（轻微去色 + 颗粒 + 1px 内描边）；缺图 → 空档案框 + 姓名首字（比随机像素人更像档案）。
- 名字牌分级：一级常显、二/三级仅悬停（现有 `.tight` 规则系统化）。
- 关系线：**线型即类型**（crew 实线 / collab 长虚线 / prod 点线 / ties 双线），颜色统一墨色 + 4 档明度；默认 opacity 0.10–0.14，聚焦 0.5，选中路径纯白。
- 时间轴：改为画布下缘的刻度尺，并与分区形成"地理 × 时间"两层叙事（拖动年份让旧线淡出），不要只做一排小按钮。

### P3 人物卡：从 HUD 到档案卡
- 删：`Lv.47`、4 格无出处数值、技能条、波形动画。
- 换：可核验计数（作品 16 / 关系 36 / 合作者 21 / 活跃 17–26 已有）。
- 加：**年度活跃条**（横轴年份，柱高=当年作品数，数据真实）；数字下方 1px 虚线下划 = 可点开来源，把"证据"做成视觉特征而非折叠角落。
- `HIGHLIGHT MOMENTS` 渐变方块 → 16:9 或 1:1 封套位（无图时空框 + 标题）；唱片符号统一为圆形黑胶。
- 分享海报（`poster.ts`）顺势升级为 press sheet：照片 + 编号 + 年度曲线 + 4 条关系。

### P4 目录页：把"世界"带进来
- 人物：改为按省份分节的名录（左侧省份索引，右侧一行一人：编号 · 姓名 · 省份 · 关系数），hover 行内浮出 3 个头像。密度反而更高，也更像档案。
- 作品：按年份分组，版本用 mono 小标签，保留 1:1 封套位。

### P5 移动端重做
- 选中人物 → 底部 sheet 只露 3 行（头像 / 姓名 / 省份 · 关系数），上滑展开；画布保持可操作。
- 画布默认只显示有人的 12 省，点省份再展开该省名单。
- 时间轴收成 32px 刻度条 + "全部"。
- 目标：390px 下最小字号 12px，可点区域 ≥ 40×40。

### P6 动效收敛
- 11 个 `infinite` → 保留 1 个（选中时关系线流动）。
- 背景 6 层 → 1 层静态纸纹/网点。
- 保留：选中 3 倍放大、拖拽反馈、抽屉滑入。
- 新增：一次性入场（节点落位 / 关系解析），替代持续躁动。

### P7 系统化收尾
- 清理 `neon.css` 的追加式覆盖，重排为 `tokens → 布局 → 组件` 三段，每选择器只出现一次。
- `style.css`（米黄纸感）**保留但限定用途**：分享海报、打印视图、空状态插画；主界面不再继承。
- 220 个 hex → 24 个 token，写进 `:root`。

## 五、验收清单（可量化）

- [ ] `<12px` 声明从 130 处降到 ≤ 10 处（仅编号/刻度）
- [ ] 所有文字对背景 ≥ 4.5:1（现 4 处不达标）
- [ ] 每个视觉单元最多 1 条边框 + 1 层阴影
- [ ] 全站唯一强调色；色相语义不重复（现 3 个关系色与省份色冲突）
- [ ] `infinite` 动画 ≤ 2；背景装饰层 ≤ 1
- [ ] 首屏焦点 ≤ 5 个（现标题/分区/名字/时间轴/rail 同时争抢）
- [ ] 390px 下最小字号 12px，画布可点区域 ≥ 40px
- [ ] 人物卡不再出现无出处的派生数值
- [ ] README 与界面数字一致

## 六、附带修掉的内容问题

- 头像说明与实际不符：README 指向 `public/avatars/`，代码实际读 `src/assets/avatars/`。
